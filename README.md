# ⚡ SMSBD.Asia — MikroTik RouterOS SMS Gateway Script

Official MikroTik RouterOS automation script for **[SMSBD.Asia](https://smsbd.asia)** — Bangladesh's fastest transactional and OTP SMS gateway.

### 🌐 Official Platforms
* 📱 **SMS Platform:** [https://smsbd.asia](https://smsbd.asia)
* 📡 **ISP ERP Solution:** [https://fibernox.com](https://fibernox.com)
* ☁️ **High-Speed Cloud Hosting:** [https://jinix.cloud](https://jinix.cloud)

---

### 🚀 Features
- Sub-3-second automated OTP & due bill notification dispatch.
- Direct MikroTik RouterOS v6 and v7 REST API / Fetch compatibility.
- Instant bKash, Nagad payment confirmation alerts.
- BTRC-approved masking and cost-effective non-masking routes.
